# Промо-ролик СМЭШ (Remotion) — бриф

## Продукт
**СМЭШ** — Telegram Mini App для брони падел-кортов в Москве. Демо для портфолио (данные тестовые).
- Живое приложение: https://ezen13.github.io/figma-demo/ (в браузере есть имитация шапки Telegram)
- Бот: https://t.me/smashpadel_bot
- Главные фишки: корт за 30 секунд, свободные слоты в реальном времени, оплата «делим на 4», открытые матчи — «не хватает игрока? найдём», рейтинг игрока.

## Визуал (коротко, детали — DESIGN.md)
- Цвета: ink `#111210`, chalk `#F1EEE4`, paper `#FBFAF5`, muted `#6E6C63`, **ball `#CCFF00` — единственный акцент**.
- Заголовки Unbounded Black/Bold, текст и цены Onest. Цены с «₽», пробел в тысячах: «4 800 ₽».
- Ощущение: спортивный плакат, скорость, диагонали, мяч со шлейфом. Не «банковское приложение».
- Нельзя: градиенты, стекло/blur, эмодзи, второй акцентный цвет, стоковые фото, мелкий капс с разрядкой.
- Кривая движения: `cubic-bezier(0.22, 1, 0.36, 1)`; удар мяча — с ускорением `cubic-bezier(0.55, 0, 1, 0.45)`.

## Ролик
- **Формат**: вертикальный 1080×1920, 30 fps, ~30 с (Reels / Shorts / Telegram). Вторым приоритетом — 1920×1080 той же сцены.
- **Язык**: русский. Тексты на экране крупные, читаются без звука.
- **Телефон**: экраны приложения в простом мокапе телефона (рисуем сами: скруглённый ink-корпус), без фото рук и сторонних мокапов.
- **Звук**: без музыки по умолчанию (лицензия!). Оставить точку подключения трека `public/music.mp3`, если пользователь пришлёт.

### Раскадровка (ориентир, можно улучшать)
| Время | Сцена | Текст на экране |
| --- | --- | --- |
| 0–2,5 с | Хук: влетает мяч со шлейфом → удар по линии корта (кольца, искры) → собирается «смэш.» (повторить анимацию из `Splash.tsx`) | — |
| 2,5–5 с | Телефон въезжает, главная «Корт на вечер?», лента кортов | **Корт на вечер?** |
| 5–10 с | Тап по корту → сетка слотов, 19:00 загорается ball, длительность 90 мин, сумма перекатывается до 4 800 ₽ | **Свободные слоты — вживую** |
| 10–14 с | Оплата: «Делим на 4» → 1 200 ₽ с игрока | **Платите только за себя** |
| 14–18 с | «Корт ваш!» — билет выезжает, перфорация | **Бронь за 30 секунд** |
| 18–23 с | Открытые матчи: схема корта, пустое место в вращающемся пунктирном кольце ball, «Присоединиться» | **Не хватает игрока? Найдём** |
| 23–26 с | Профиль: график рейтинга растёт до 3,4 | **Растите в рейтинге** |
| 26–30 с | Финал: ink-фон, «смэш.», плашка ball «Открыть в Telegram», @smashpadel_bot | **@smashpadel_bot** |

## Исходники экранов
Предпочтительно: свежие скриншоты живого приложения в 3× (Playwright, ширина 390, deviceScaleFactor 3) с https://ezen13.github.io/figma-demo/ — поверх них анимировать выделения, тапы (кружок-касание), перекат цифр. Графику (мяч, корт, логотип) — векторно, переиспользуя `smash-app/src/graphics/`.
Dev-флаги приложения: `?splashAt=<мс>` замораживает кадр сплэша (только в dev-сборке `npm run dev`).

## Результат
- Проект Remotion в `promo/` этого репозитория (не трогать `smash-app/`).
- Рендер: `promo/out/smash-promo-9x16.mp4` (+ `smash-promo-16x9.mp4`), H.264, ≤ 30 МБ.
- Постер-кадр PNG.
- Перед финальным рендером показать пользователю 3–4 стоп-кадра на согласование.
- Лицензия Remotion: бесплатна для частных лиц и компаний до 3 человек — ок для этого демо.
